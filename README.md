# Portfolio Website

Een eenvoudige persoonlijke portfoliowebsite gebouwd met HTML, CSS en JavaScript.

## Structuur

```
├── index.html        # Hoofdpagina
├── css/
│   └── styles.css    # Stijlen
├── js/
│   └── script.js     # Functionaliteit
└── images/           # Afbeeldingen voor projecten
```

## Functies

- Responsief ontwerp (mobiel-vriendelijk)
- Navigatiemenu met hamburger-menu op mobiel
- Secties: Home, Over mij, Projecten, Contact
- Contactformulier
- Projectenpagina met detailpopups (screenshots, technieken en links naar demo en GitHub)
- Scroll-animaties
- Een website over joris van der mispel
- ik vindt programeren in php intressand
- mijn leerdoelen
## Gebruik

Open `index.html` in een browser.
